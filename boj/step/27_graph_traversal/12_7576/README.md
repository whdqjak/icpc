# boj 7576_토마토

## 문제
-박스(2차원 배열)가 익은 토마토, 안익은 토마토, 빈칸으로 구성되어 있음
-하루가 지나면 익은 토마토 바로 옆(대각선 안됨)에 있는 토마토는 익은 토마토로 바뀜

-몇일이 지나야 전부 익은 토마토로 바뀌는지 구하기
(만약 아얘 익지 못하는 토마토가 있으면 -1 출력)

## 문제특징
-기존 bfs는 시작점이 하나 였는데 얘는 여러개임
-그래서 큐에 시작점들을 미리 넣어줌
-시작점들에 번째 수를 부여해서(0으로) 시작점들이 동일하게 bfs탐색할 수 있게 함
(현재 방문한 점의 번째 수 = 부모(?)의 번째 수)
