# boj 1707_이분 그래프

## 문제
-이분그래프인지 아닌지 판별하기

## 해결방법
-일단 이분그래프의 정의는 정점들을 두 집합으로 분류했을 때 각각 집합끼리의 정점들끼리는 간선이 연결되어 있지 않고 서로 다른 집합의 정점끼리만 간선이 연결되어 있는 그래프(연결이 되어있지 않은 정점이 있어도 됨)

-같은 의미의 다른 정의?가 있음
그래프에 홀수 길이 사이클이 존재하지 않는다.
(즉, 인접한 정점들끼리는 서로 다른 색깔로 칠 할 수 있으면 된다.)

-그래서 그냥 bfs나 dfs로 순회하면서 각 정점을 다른색깔로 칠하면 됨
만약에 그럴 수 없다며 이분그래프가 아니다

## 새롭게 알게 된 점
-이분 그래프 말고도 알게된게 있음
assign()인데 재초기화(재선언) 해주는 함수임.
전역으로 선언하고 싶은데 이러면 따로 초기화를 해줘야해서 난감했는데 이게 딱이었음!
(assign(초기화할 값의 갯수, 초기화할 값))

-assign()함수는 vector같은 시퀀스 컨테이너에 있음
(set이나 map같은 거엔 없음)
(+fill도 괜찮음 fill(시작점, 끝점, 초기화할 값))
-추가로 memset은 저수준(정적배열)에만 쓰기
