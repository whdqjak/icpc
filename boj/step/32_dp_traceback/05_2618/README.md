# boj 2618_경찰차

## 문제
-두 경찰차가 사건들을 순서대로 처리할 때
-총 이동 거리의 최솟값 구하기 + 어떤 경찰차가 처리했는지 출력 (역추적)

## 이번 문제에서 얻은 깨달음
-dp저장방식?을 메모리를 너무 과하게 쓰는거 같으면 다른 관점으로 푸는걸 고려(상태 중심으로?)
N개의 사건을 p1,p2 에서 해결~ --> p1, p2가 마지막으로 해결한 사건 기준으로 ~

-경로는 따로 역추적으로 복원해야 한다

### 상태 정의가 전부다 (좌표로 들고다니면 망함)

-처음에 `(p1, p2)` 좌표 자체를 상태로 들고 가려고 했는데
  → 상태 수 터져서 절대 못 품

-핵심은
dp[a][b]
a: 경찰차1이 마지막으로 처리한 사건 번호
b: 경찰차2가 마지막으로 처리한 사건 번호
좌표 → 인덱스로 상태 압축..

### DP에서 경로를 저장하려고 하면 망함

-처음에 이런 식으로 했었음
DP 함수 안에서 push 
tb.push_back(1);

-같은 상태가 여러 번 호출됨 (중복 상태)
그때마다 push됨

### trace에서 dp 직접 쓰면 안되는 이유

처음에 이렇게 했었음
int m1 = dp[next][b] + ...

-dp가 아직 안 채워진 상태일 수 있음
특히 재귀 DP는 모든 상태가 미리 계산되지 않음
