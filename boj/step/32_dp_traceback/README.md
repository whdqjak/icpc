-dp로 구하는 방법

이거는 이해가 나름 잘 됐음 dp[i]를 기준으로
i번째 원소보다 작은 k(i>k)번째 원소들이 후보임
이어붙인것중에 가장 긴거가 정답


-이분탐색으로 구하는방법

이건 이해가 잘 안됐었음

수열의 원소들을 차례대로 읽으면서 큰 원소들은 계속 저장하고
작은 원소들이 자기보다 작은 마지막 원소 앞의 원소를 대체함

이게 어떤 느낌이냐면
수열을 구성하고 있는데 거기에 작은값이 들어왔을 때
작은값으로 이루어진 수열이 정답후보가 될수도 있으므로 작은값이 올 수 있는 위치에 놓고(삽입이 아니라 대체가 포인트인듯!)
작은값을 받아들이기 전의 후보는 길이로써 정보를 가지고 있기 때문에 대체해도 상관 없다.
