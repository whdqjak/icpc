# boj 11049_행렬 곱셈 순서

## 문제 
-행렬곱셈 ABCD...를 할 때 연산횟수가 가장 적을 때 몇번 해야하는지 구하기


## 행렬곱셈
-N*M 과 M*K를 곱하면 N*K행렬이 나옴
(행렬을 서로 곱할 땐 가운데 크기가 같아야함)


## 해결방법
-그냥 평범한 dp로 [i...j]까지 곱했을 때 결과를 저장하면서 구하면 됨


## 실수, 반성
-자료형 크기 또 신경 잘 안씀
-탑다운 말고 바텀업도 잘해야함..

-바텀업은 항상 밑에서부터인데 구할 수 있는것부터 구하면서 올라가야함
(탑다운에서 함수호출되는 순서랑 똑같음)
-이번문제같은경우는 바텀업으로 하면 길이를 늘리면서 구하기
