# boj 3665_최종 순위

## 문제
-작년 대회 순위가 주어지고 올해 순위가 뒤바뀐 팀들의 명단이 주어졌을 때
올해 대회 순위를 맞추는 문제

-만약 답이 여러개면 ? 를 출력
답이 없으면 IMPOSSIBLE 출력

## 문제 해결 아이디어
-위상정렬하면서 큐에 들어간 원소가 1개가 아니면 답이 여러개일 수 있으므로 ? 출력
-위상정렬하면서 아직 다 완성하지도 않았는데 큐가 비어서 더이상 뺄 원소가 없다면 위상정렬 불가능이므로 IMPOSSIBLE 출력
(기존에는 while(!q.empty())로 했다면 이번문제는 for문으로 했음(정점 개수가 n개니까 n번 반복)
이유는 empty()를 따로 확인해야하기 때문)

## 내가 느낀점
-첫번째로 나는 처음에 순위가 주어졌을 때 그걸 방향그래프로 나타낼려할 때 단순히 1-2-3-4-5 이런식으로 이을려했음
근데 이러면 문제가 생긴다 예를 들면 1이랑 5랑 우선순위가 바뀔 때 나머지에 대해서 다 수정을 해줘야함
아래처럼 하면 그러지 않아도 된다. 그냥 1에서 5로 가는 간선을 5에서 1로 가는 간선으로 바꾸면 위상정렬 했을 때 자연스럽게 1보다 5가 먼저 나온다
1-(2,3,4,5)
2-(3,4,5)
..

-두번째는 인접행렬로 할지 인접리스트로 할지 잘 생각해봐야 한다는 것이다.
이번문제를 통해 알게된 건 간선이 많을수록 인접리스트보단 인접행렬이 훨씬 좋다는 것이다
구체적으로는 간선의 갯수가 정점의 제곱에 가까워질수록 그렇다
(인접행렬은 메모리가 낭비가 좀 있고, 간선 수정, 정점 간 연결 확인 이런게 빠름)
(인접 리스트는 수정 등이 느리지만 메모리 낭비가 없음)
