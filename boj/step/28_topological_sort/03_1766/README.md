# boj 1766_문제집

## 문제
-N개의 문제(1번부터 N번)가 있을 때(난이도는 문제번호가 클수록 어려움) 조건에 맞게 문제를 푸는 순서를 출력하는 문제

-조건
N개의 문제는 모두 풀어야 한다.
먼저 푸는 것이 좋은 문제가 있는 문제는, 먼저 푸는 것이 좋은 문제를 반드시 먼저 풀어야 한다.
가능하면 쉬운 문제부터 풀어야 한다.

먼저 푸는것이 좋은 문제라는 것은 입력이 (k, i) 일때 
k번 문제를 i번 문제보다 더 먼저 풀어야한다는 뜻

## 해결 방법
-그냥 위상정렬인데 먼저푸는 것이 좋은 문제 정보를 가지고 간선 수정을 한 후에
나올 수 있는 위상정렬케이스 중에서 가장 알맞은 케이스(사전순)를 출력하는 문제

-간선 수정은 예를 들어서 a, b를 입력받으면 a는 단순히 b보다 먼저 풀어야하는 문제로 바뀜
(전에는 b-1보다 나중에 풀려야 하고 b+1보다 먼저 풀려야 하는 문제였다면)

-위상정렬에서 큐대신 우선순위 큐를 쓰면 됨

-추가로 그래프간선 연결을 3665번 처럼 1번은 2번부터 N번까지, 2번은 3번부터 N번까지 이렇게 쭉 연결하는게 아님!(문제 번호 자체가 자기의 위상순서를 나타내고 있으므로 간선수정이 일어난 것만 그래프에 
나타내어 주면 됨)
