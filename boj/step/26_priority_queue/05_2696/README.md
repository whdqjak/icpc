# boj 2969_중앙값 구하기

## 문제
-어떤 수열을 입력받을 때 홀수번째 항을 입력받을 때마다 현재까지의 수열의 중앙값을 출력하는 문제.

## 아이디어
-중앙값을 기준으로 왼쪽은 최대힙, 오른쪽은 최소힙을 놓고 최대힙과 최소힙의 size()를 1만큼 차이나게 두면 된다.
중요한 점은 항상 최대힙의 모든 원소 < 최소힙의 모든 원소!

-기준을 최대힙으로 잡고 만약 size()가 같으면 최대힙에 새로운 원소를 넣고 
size()가 최대힙이 1 크면 최소힙에 원소를 넣는다.
그 후에 만약에 최대힙의 top() > 최소힙의 top() 이면 최소힙과 최대힙의 top()를 swap해준다.
(여기서 swap은 각 힙의 top()를 상대의 힙에 옯겨 다시 삽입시키는 과정)
