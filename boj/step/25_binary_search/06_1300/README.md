# boj 1300_K번째 수

## 문제
-N*N크기의 2차원 배열A가 있고 각 원소 A[i][j] = i*j, A의 인덱스는 1부터 시작.
-N*N크기의 1차원 배열B가 있고 A의 원소들을 배열 B에 옮기고 오름차순 정렬, B의 인덱스도 1부터 시작.
-K를 입력받았을 때 B[K] 구하기

## 아이디어
-이분탐색을 이용하여 B[K]가 될 수 있는 값 찾기.
처음에 될 수 있는 값의 범위는 (1, N*N)
B[K]의 최댓값은 N*N, K = min(1e9, N*N) 이므로 B[K]는 1e9보다 커질 수 없음
처음이 될 수 있는 값의 범위는 (1, 1e9)

## 핵심 key
-B[K]: 배열 A에서 자기 보다 작거나 같은 수가 K개 이상이면서
자기 보다 큰수의 갯수가 N-K보다 작거나 같은 수

-이분탐색을 하면서 현재 mid값이 답인지 추측할 때
배열 A에서 mid값보다 작은 값이 몇개 있는지(L) 알아내야 함 
-전의 mid에서 (L)값이 K보다 작았는데 현재 mid에서 (L)값이 K보다 크거나 같다면
그 값이 정답.

-(L)을 구하는 방법..
A[i][j] = i * j 이고, i는 1~N.

고정된 i에 대해
i * j ≤ mid 를 만족하는 j는 j ≤ mid / i ,
j는 N보다 커질 수 없으므로 min(N, mid / i)

i를 1부터 N까지 움직이면서 i * j ≤ mid 를 만족하는 j의 갯수(=mid보다 작은 수) 찾기
