# boj 12015_가장 긴 증가하는 부분 수열 2

## 문제
-lis 길이 구하는 문제.
-제한시간이 짧아서 dp방식으로는 시간초과가 난다.

## 내가 처음에 했던 생각
-전에 풀었던 이분탐색을 생각해서 이번에도 답이 될 수 있는 범위를 정해두고
이분탐색을 이용해서 답을 찾아가는 방식을 시도.
-막힌 부분이 있었는데 이분탐색을 하면서 현재 mid값이 정답인 lis의 길이보다 큰지 작은지
판단 어려웠음.

## 문제해결 방법
-dp[i] : 길이가 i인 증가하는 부분 수열 중, 마지막 원소의 최솟값
항상 dp 배열은 오름차순을 유지하도록 관리한다.

-같은 길이의 증가 부분 수열이라면, 마지막 값이 작을수록 이후에 더 긴 수열로 확장될 가능성이 크다
이므로 dp[i]를 가능한 한 작게 유지하는 것이다.

-처리 과정
수열을 앞에서부터 하나씩 확인한다.
현재 값 x에 대해:
dp의 마지막 값보다 크다면 새로운 길이의 증가 부분 수열을 만들 수 있으므로 dp 뒤에 추가

그렇지 않다면:
이분탐색(lower_bound)를 이용해 x가 들어갈 수 있는 위치를 찾아 그 값을 x로 갱신

이때 갱신은 수열의 길이를 늘리기 위한 것이 아니라,
같은 길이의 부분 수열을 더 좋은 상태(마지막 값이 더 작게)로 바꾸는 역할을 한다.

-결과
dp 배열의 길이가 곧 가장 긴 증가하는 부분 수열(LIS)의 길이가 된다.
실제 LIS 수열을 저장하지는 않지만, 길이는 정확하게 계산된다.
전체 시간 복잡도는 O(N log N).

-주의할 점
dp는 실제 부분 수열이 아니다.
dp[i] < dp[i+1] 관계는 유지되지만, 인덱스가 실제 원소의 순서를 의미하지는 않는다.
