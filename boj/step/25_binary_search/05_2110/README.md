# boj 2110_공유기 설치

## 문제
-수직선 상에 N개의 집이 있고 각 집의 좌표가 주어짐
-공유기 C개를 집에 설치해야하는데 가장 인접한 두 공유기 사이의 거리(L)를 가능한 크게 설치해야 함
-(L)의 최댓값 구하기

## 해결방법
-(L)이 될 수 있는 값의 범위를 정하고 이분탐색으로 탐색
(0 ,마지막집 - 처음 집)

-검사하는 법은 집을 하나씩 돌면서
전에 설치했던 집과 현재 집의 거리가 mid값보다 크면 설치하면서 설치한 공유기의 갯수를 세기

-설치한 공유기의 갯수가 C보다 적다면 high를 내리고 반대면 low를 올리기

-정답이 될 수 있는것은 C개 이하로 설치를 하는것이기 때문에(C개보다 더 많이 설치할 순 없음)
C보다 적은 쪽(high)을 계속 정답으로 업데이트
